Eski Paylaşımlı Port (8080) vs Yeni İzole Loopback Mimarisi (PO-U5-03)

Eski Tek Port (8080) .test Mimarisi:
  • macOS DNS .test alan adlarını 127.0.0.1'e çözmez (NXDOMAIN).
  • Kullanıcının sudo ile /etc/hosts dosyasını elle düzenlemesi gerekir.
  • Ham IP üzerinden açıldığında yanlış proje gelebilir.
Yeni İzole Loopback Port Mimarisi:
  • 127.0.0.1 doğrudan IP katmanında çözülür; sıfır DNS bağımlılığı.
  • Sudo veya /etc/hosts müdahalesi kesinlikle gerekmez.
  • Port 18082 yalnızca Projetest'i sunar; çapraz kirlenme imkansızdır.
